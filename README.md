# Governança de IA — Escola Datarock

Kit do aluno do curso Governança de IA. Aqui estão os casos fictícios, os enunciados e os modelos para preencher. As aulas e as respostas comentadas ficam na plataforma do curso.

## Como usar

Baixe os arquivos em **Code → Download ZIP** e extraia a pasta. Abra o README da aula que está estudando e siga as instruções. Você também pode ler os arquivos diretamente no GitHub.

Estas atividades usam um editor de texto e um navegador. Não exigem terminal, instalação de pacotes ou conta de IA. Depois de baixar os arquivos, você pode fazer os exercícios sem internet; a consulta às fontes oficiais exige conexão.

| Aula | Pasta |
|---|---|
| 00. Apresentação | [00-apresentacao](00-apresentacao/) |
| 01. Governança, risco e responsabilidade | [01-governanca-risco-e-responsabilidade](01-governanca-risco-e-responsabilidade/) |
| 02. Inventário de casos de uso | [02-inventario-de-casos-de-uso](02-inventario-de-casos-de-uso/) |

Salve uma cópia dos modelos antes de escrever. Os relatos da Loja Exemplo e os assistentes mencionados são fictícios. Use os dados dos enunciados, sem incluir dados pessoais ou documentos do trabalho.
