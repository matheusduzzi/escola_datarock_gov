# Kit de Governança de IA: Apresentação

Abra [caso.md](caso.md), leia [exercicio.md](exercicio.md) e salve uma cópia de [minhas-respostas.md](minhas-respostas.md). Escreva nessa cópia. Feche e abra o arquivo para ver se suas respostas ficaram salvas.

No kit completo do curso, esses arquivos ficam em `00-apresentacao/`. Os nomes usados na aula partem dessa pasta. Aqui, os arquivos estão juntos para você trabalhar na apresentação.

Você precisa de um editor de texto e de um navegador. Markdown abre como texto comum. O diagnóstico funciona sem internet depois de baixar os arquivos; as consultas a fontes oficiais precisam de conexão. Não há pacote para instalar, comando para rodar ou conta de IA para criar nessa atividade.

Comece pelas tarefas que consegue fazer. Depois escolha uma dificuldade e preencha seu plano de estudo. Você usa o caso fornecido; não inclua dados pessoais ou documentos do trabalho.

Para pedir ajuda, deixe um comentário na aula com seu objetivo, o passo ou comando usado, o resultado e o que já tentou, sem dados pessoais.
