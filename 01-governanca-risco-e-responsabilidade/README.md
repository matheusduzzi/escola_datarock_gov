# Kit: Governança, risco e responsabilidade

Você entrega um mapa de responsáveis para o uso de IA na fila de reclamações da Loja Exemplo.

1. Leia [o exercício](exercicio.md), que traz todos os fatos do caso.
2. Abra [o modelo do mapa](modelo-mapa.md) em um editor de texto. Salve uma cópia como `meu-mapa.md`.
3. Escreva suas decisões, os motivos e o que ainda precisa de definição.
4. Use os critérios do exercício para reler o mapa antes de entregar.

Os caminhos partem da pasta dessa aula no kit. Markdown é um formato de texto; um editor comum abre esses arquivos. Você também pode copiar os campos para outro documento.

Não há instalação, pacote, terminal ou conta de IA para essa atividade. Depois de baixar os arquivos, você pode fazer o exercício sem internet. A leitura das referências da aula usa o navegador.

O caso e o modelo foram escritos para esse material. Use os fatos do enunciado, sem colocar dados pessoais. Os arquivos não trazem a solução do exercício. A resposta da prática guiada fica na página da aula.

Se precisar de ajuda, deixe um comentário na aula com seu objetivo, o passo ou comando usado, o resultado e o que já tentou.
